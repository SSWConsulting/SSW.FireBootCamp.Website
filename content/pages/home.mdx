          You’ll work with .NET, Angular, Entity Framework Core, and SQL Server

      - question: What will I be building?
        answer: >-
          You’ll start with .NET and Angular fundamentals, then finish by
          building a complete full-stack application.
      - question: Do I need prior coding experience?
        answer: >-
          Yes. A Computer Science degree or equivalent experience, basic SQL,
          relational databases, object-oriented programming, and JavaScript
          knowledge are recommended.
      - question: What is the application process?
        answer: >-
          Apply online, complete an initial interview, then a short coding task
          for scholarship eligibility. Day one starts with meeting the team and
          jumping straight into the course.
      - question: Is online learning an option?
        answer: >-
          FireBootCamp is currently delivered in person to maximise hands-on
          learning, with online options planned for the future.
      - question: Is the course full time?
        answer: >-
          Yes. It runs full time, Monday to Friday, 9am–6pm, for 12 weeks, with
          limited part-time flexibility in some cases.
      - question: Do I need to bring a laptop?
        answer: >-
          Yes. You’ll need a laptop with at least an i5 or equivalent CPU, 32GB
          RAM, 512GB SSD, a Full HD display, and good battery life.
      - question: Do I need software licenses?
        answer: >-
          No paid licenses are required. Optional tools like GitHub Copilot are
          encouraged but not mandatory.
